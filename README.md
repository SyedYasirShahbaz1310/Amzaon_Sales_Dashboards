**# 📊 Amazon Sales Performance Analytics Dashboard (Power BI)**

## 📋 Overview
This repository contains a comprehensive, interactive Power BI dashboard designed to analyze **Amazon Sales Data**. The primary objective of this project is to transform raw e-commerce transaction logs into actionable business insights—enabling stakeholders to track sales performance, optimize inventory, evaluate product margins, and understand customer purchasing behavior.

---

## 💡 Key Insights & Dashboard Features

The data model and visual layouts are engineered to extract and present the following critical business insights:

* **Sales & Revenue Dynamics:** Tracks Month-over-Month (MoM) and Year-over-Year (YoY) revenue trends to identify seasonal peaks, prime shopping days, and historical growth patterns.
* **Product Performance Analytics:** Evaluates which product categories and specific sub-categories drive the highest sales volume versus which ones yield the best profit margins.
* **Geographical Distribution:** Maps order volume by Country, State, and City, allowing marketing and logistics teams to pinpoint high-demand territories.
* **Order Status & Supply Chain Health:** Monitors the ratio of Shipped, Delivered, Cancelled, and Returned orders to identify potential bottlenecks in fulfillment.
* **Customer Purchasing Patterns:** Breaks down average order values (AOV) and basket sizes to understand consumer behavior and segmentation.

---

## 🛠️ Project Architecture & Technical Specs

* **Analytics Tool:** Power BI Desktop
* **Data Modeling:** Built using an optimized Star Schema/Snowflake Schema to ensure efficient relationships and fast visual rendering.
* **DAX Implementation:** Features advanced custom measures for key metrics including *Total Revenue, Net Profit, Profit Margin %, YoY Growth*, and *Moving Averages*.
* **UI/UX Optimization:** Utilizes a decoupled visual design layout supported by a clean global theme (`CY26SU04.json`) and compressed canvas backgrounds (`Dashboard_Canvas_Background.jpg`) to maximize dashboard loading speed and maintain a modern corporate aesthetic.
